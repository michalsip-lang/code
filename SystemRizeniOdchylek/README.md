# Systém řízení odchylek

Základ projektu pro evidenci, vyšetřování, vyhodnocování a uzavírání odchylek.

## Struktura

- `apps/` — samostatné aplikace spouštěné na localhostu.
- `documents/` — postupy, šablony, specifikace a exporty.
- `shared/` — společné datové modely, pravidla a komponenty.

## První doporučená aplikace

`apps/evidence-odchylek/` — formulář a přehled odchylek se stavy: založena, v šetření, návrh CAPA, schválena, realizace, ověření účinnosti a uzavřena.

Každá aplikace bude mít vlastní návod ke spuštění a lokální adresu.
