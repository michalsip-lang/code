# Řízení změn

Základ pro aplikace a dokumentaci procesu řízení změn.

## Struktura

- `apps/` — samostatné lokálně spouštěné aplikace.
- `documents/` — specifikace, postupy, šablony a exporty.
- `shared/` — společná pravidla, datové modely nebo komponenty.

## Spouštění aplikací

Každá aplikace bude mít vlastní `README.md` s přesným příkazem ke spuštění a adresou localhostu. Až přibude první aplikace, stačí napsat například „spusť aplikaci evidence změn“.

## První doporučená aplikace

`apps/evidence-zmen/` — evidence požadavků na změnu: návrh, posouzení dopadu, schválení, realizace, ověření a auditní historie.
